# PRD: todo-list

## Executive Summary

一個給自己日常使用的待辦事項管理工具，以純前端（HTML/CSS/JavaScript）實作，資料儲存在瀏覽器 localStorage，不需後端或帳號系統。核心價值是快速記錄、分類與排序待辦事項，並在頁面上以視覺方式提示即將到期或已逾期的項目。

## Problem Statement

目前沒有一個順手、輕量的個人待辦工具可以記錄日常任務、依分類/優先順序管理，並在到期前後給予明確的視覺提醒。需要一個開發成本低、可以馬上開始使用的解決方案。

**為什麼是現在**：作為練習專案的下一步，先以最小技術堆疊（純前端）快速產出可用工具，之後可視需要再擴充。

## User Stories

### 使用者角色
單一使用者（僅自己），無需帳號或登入。

### 使用者故事

1. 作為使用者，我想要新增一筆待辦事項，包含標題、分類/標籤、優先順序與截止日期，以便完整記錄任務資訊。
   - 驗收標準：可輸入標題（必填）、選擇或建立分類/標籤、選擇優先順序（高/中/低）、設定截止日期（可留空）。

2. 作為使用者，我想要將待辦事項標記為完成，以便追蹤進度。
   - 驗收標準：點擊即可切換完成/未完成狀態；已完成項目在清單中有明顯的視覺區隔（例如刪除線或移到清單底部）。

3. 作為使用者，我想要編輯已建立的待辦事項，以便修正或更新內容。
   - 驗收標準：可修改標題、分類/標籤、優先順序、截止日期；儲存後立即反映在清單上。

4. 作為使用者，我想要刪除不需要的待辦事項，以便保持清單乾淨。
   - 驗收標準：刪除前需二次確認；刪除後項目立即從清單與 localStorage 中移除。

5. 作為使用者，我想要依分類/標籤篩選待辦事項，以便專注在特定範圍的任務。
   - 驗收標準：可依單一分類/標籤篩選清單；提供「顯示全部」選項。

6. 作為使用者，我想要依優先順序排序待辦事項，以便先處理重要任務。
   - 驗收標準：清單可依優先順序（高→低）排序；排序方式可切換。

7. 作為使用者，我想要在清單中一眼看出哪些任務已逾期或即將到期，以便及時處理。
   - 驗收標準：已逾期項目以醒目樣式（如紅色）標示；即將到期（例如 24 小時內）以另一種醒目樣式（如橘色/黃色）標示；此提示為頁面內視覺呈現，不涉及瀏覽器推播通知。

8. 作為使用者，我想要重新整理頁面或重新開啟瀏覽器後，之前輸入的待辦事項仍然存在，以便持續使用不遺失資料。
   - 驗收標準：所有待辦事項資料存於瀏覽器 localStorage，重新載入頁面後資料維持不變。

## Functional Requirements

- **待辦事項 CRUD**：新增、檢視、編輯、刪除待辦事項。
- **欄位**：每筆待辦事項包含標題（必填）、分類/標籤（可複選或單選，可自訂）、優先順序（高/中/低）、截止日期（選填）、完成狀態。
- **分類/標籤管理**：使用者可自訂分類/標籤名稱；待辦事項可依分類/標籤篩選。
- **優先順序排序**：清單可依優先順序排序（高→中→低）。
- **到期提醒（視覺化）**：
  - 已逾期（截止日期早於目前時間且未完成）→ 醒目標示。
  - 即將到期（例如截止日期在 24 小時內且未完成）→ 另一種醒目標示。
  - 無截止日期的項目不參與此邏輯。
- **完成狀態切換**：可將待辦事項標記為完成/未完成，已完成項目在清單中有明顯區隔。
- **資料持久化**：所有資料讀寫皆透過瀏覽器 localStorage，無需伺服器或帳號。

## Non-Functional Requirements

- **效能**：待辦事項數量在數百筆以內時，新增/篩選/排序操作應在使用者感知範圍內（不到 1 秒）完成。
- **相容性**：支援現行主流桌面瀏覽器（Chrome、Edge、Firefox 最新版）。
- **可用性**：介面以純 HTML/CSS/JavaScript 實作，操作直覺，無需說明文件即可上手。
- **無安全性/隱私考量**：因無帳號系統且資料僅存於使用者自己的瀏覽器本機，不涉及多使用者資料保護或傳輸加密需求。

## Success Criteria

- 可在瀏覽器中完成待辦事項的新增、編輯、刪除、標記完成，且重新整理頁面後資料不遺失。
- 可依分類/標籤篩選、依優先順序排序清單。
- 逾期與即將到期的待辦事項能在清單中被明確、一眼辨識。
- 全程不需要後端服務、資料庫或使用者登入即可正常運作。

## Constraints & Assumptions

- 技術堆疊限定為純前端 HTML/CSS/JavaScript，本階段不建置後端或 API。
- 資料儲存於瀏覽器 localStorage，僅存在於單一瀏覽器/單一裝置內，不同裝置或清除瀏覽器資料後不會保留。
- 僅單一使用者使用，不需帳號、登入或權限管理。
- 到期提醒僅為頁面內視覺呈現，不使用瀏覽器 Notification API 或任何推播機制。

## Out of Scope

- 多人協作或共享待辦清單。
- 重複性任務（每日/每週自動重複產生新項目）。
- 帳號登入與權限管理系統。
- 原生手機 App 或 PWA 離線功能。
- 跨裝置資料同步（目前僅單機 localStorage，未來如有需要可另行規劃為新的 PRD）。
- 瀏覽器推播通知（Notification API）。

## Dependencies

無外部系統或團隊依賴。純前端專案，僅依賴使用者的瀏覽器執行環境。
