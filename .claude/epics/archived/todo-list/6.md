# Task: 分類/標籤篩選

## Description

讓使用者可以依分類/標籤篩選目前顯示的待辦事項清單，並提供「顯示全部」選項還原完整清單。

## Acceptance Criteria
- [ ] 頁面提供分類/標籤篩選控制項（例如下拉選單），選項來自目前所有待辦事項中出現過的分類/標籤。
- [ ] 選擇特定分類/標籤後，清單只顯示符合條件的待辦事項。
- [ ] 提供「顯示全部」選項，選擇後清單還原顯示所有待辦事項。
- [ ] 篩選狀態不影響 localStorage 中的原始資料，僅影響畫面顯示。

## Technical Details

- 篩選邏輯在 `app.js` 中對記憶體陣列做 filter，再呼叫既有的渲染函式，不需修改 `storage.js`。
- 分類/標籤選項清單可在每次渲染時動態從目前資料中去重取得。

## Dependencies

- Task 1（資料層）與 Task 2（清單渲染）需先完成。
