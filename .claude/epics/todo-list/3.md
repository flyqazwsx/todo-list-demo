# Task: 新增與清單渲染

## Description

實作新增待辦事項的表單（標題／分類標籤／優先順序／截止日期），送出後透過 `storage.js` 寫入資料，並將目前所有待辦事項渲染成清單顯示在頁面上。

## Acceptance Criteria
- [ ] 表單包含：標題（必填）、分類/標籤（文字輸入或下拉）、優先順序（高/中/低）、截止日期（可留空）。
- [ ] 標題為空時無法送出，並顯示提示訊息。
- [ ] 送出後呼叫 `storage.js` 寫入新待辦事項，並清空表單。
- [ ] 頁面載入時自動讀取 localStorage 中的待辦事項並渲染成清單。
- [ ] 每筆待辦事項清單項目顯示標題、分類/標籤、優先順序、截止日期。
- [ ] 重新整理頁面後，先前新增的待辦事項仍然顯示（驗證與 Task 1 資料層整合正確）。

## Technical Details

- 清單渲染建議採「整批重繪」策略：每次資料異動後清空容器並依目前記憶體陣列重新產生 DOM。
- 表單與清單邏輯放在 `app.js`，透過 `storage.js` 提供的函式存取資料，不直接操作 localStorage。

## Dependencies
