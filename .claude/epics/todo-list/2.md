# Task: 專案骨架與資料層

## Description

建立專案的基本檔案結構（`index.html`／`style.css`／`app.js`／`storage.js`），並實作 `storage.js` 作為 localStorage 存取的封裝層，提供給後續所有任務使用。

## Acceptance Criteria
- [ ] `index.html`／`style.css`／`app.js`／`storage.js` 四個檔案建立完成，並正確互相連結（`<link>`／`<script>`）。
- [ ] `storage.js` 提供 `loadTodos()`、`saveTodos(todos)` 函式，讀寫 localStorage 中的待辦事項陣列。
- [ ] `storage.js` 提供 `addTodo()`、`updateTodo()`、`deleteTodo()`、`getTodos()` 等 CRUD 函式（依實作需要可調整命名，但需涵蓋新增/更新/刪除/查詢）。
- [ ] localStorage 中不存在資料時，自動初始化為空陣列，不會拋出錯誤。
- [ ] 開啟 `index.html` 可正常載入，瀏覽器主控台無錯誤訊息。

## Technical Details

- 待辦事項資料結構建議：`{ id, title, category, priority, dueDate, completed, createdAt }`。
- `id` 可用時間戳記或簡單遞增計數器產生，避免依賴額外套件。
- localStorage 的 key 命名建議：`todo-list:todos`。

## Dependencies

無（此任務為其他所有任務的前置基礎）。
