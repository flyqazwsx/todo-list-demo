# Task: 到期提醒視覺化

## Description

依截止日期計算每筆待辦事項的到期狀態（已逾期／即將到期／正常），並在清單中以不同樣式醒目標示，純頁面內視覺呈現，不使用瀏覽器推播通知。

## Acceptance Criteria
- [ ] 未完成且截止日期早於目前時間 → 判定為「已逾期」，套用醒目樣式（例如紅色）。
- [ ] 未完成且截止日期在目前時間起 24 小時內 → 判定為「即將到期」，套用另一種醒目樣式（例如橘/黃色）。
- [ ] 已完成的待辦事項不套用逾期/即將到期樣式，即使截止日期已過。
- [ ] 沒有設定截止日期的待辦事項不參與此邏輯，維持一般樣式。
- [ ] 邊界情況（例如剛好卡在 24 小時門檻）判斷正確，不會出現誤判。

## Technical Details

- 到期狀態計算函式建議獨立封裝（例如 `getDueStatus(todo)`），回傳 `overdue`／`dueSoon`／`normal`，供渲染時套用對應 CSS class。
- 時間比較使用 `Date` 物件與目前時間 `new Date()` 相減取得毫秒差，轉換為小時判斷門檻。
