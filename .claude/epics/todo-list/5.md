# Task: 編輯與刪除

## Description

讓使用者可以編輯既有待辦事項的所有欄位，以及刪除不需要的待辦事項（刪除前需二次確認）。

## Acceptance Criteria
- [ ] 每筆待辦事項提供「編輯」入口，可修改標題、分類/標籤、優先順序、截止日期。
- [ ] 編輯儲存後，清單立即反映更新後的內容，並寫回 localStorage。
- [ ] 每筆待辦事項提供「刪除」按鈕，點擊後需二次確認（例如 `confirm()` 對話框）。
- [ ] 確認刪除後，該項目立即從清單與 localStorage 中移除。
- [ ] 取消刪除確認時，項目維持不變。

## Technical Details

- 編輯可採「表單填入既有值 + 儲存覆蓋」的方式，重用 Task 2 的表單元件。
- 刪除與編輯皆透過 `storage.js` 提供的 `deleteTodo()`／`updateTodo()` 完成。

## Dependencies

- Task 1（資料層）與 Task 2（清單渲染）需先完成。
