# Task: 完成狀態切換

## Description

讓每筆待辦事項可以切換完成/未完成狀態，並在清單中對已完成項目給予明顯的視覺區隔。

## Acceptance Criteria
- [ ] 每筆待辦事項旁有可點擊的元件（如 checkbox）用來切換完成狀態。
- [ ] 切換後立即更新畫面樣式（例如：標題加上刪除線、整體淡化）。
- [ ] 切換後透過 `storage.js` 寫回 localStorage，重新整理頁面後狀態保持。
- [ ] 已完成項目在清單中位置明顯區隔（例如排在未完成項目之後）。

## Technical Details

- 沿用 Task 2 建立的清單渲染邏輯，在渲染時依 `completed` 欄位套用不同的 CSS class。
- 切換狀態的操作透過 `storage.js` 的 `updateTodo()` 完成，不直接修改 localStorage。

## Dependencies

- Task 1（資料層）與 Task 2（清單渲染）需先完成。
